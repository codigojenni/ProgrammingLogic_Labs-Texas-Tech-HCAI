## Projects

### Video Rental Calculator

Calculates the total cost of a movie rental based on the number and type of movies rented and the number of rental nights.

**Concepts:** User input, variables, arithmetic operations, and formatted output.

### Employee Pay Calculator

Calculates an employee's weekly pay using regular and overtime hours. The main program uses a separate Python module containing a reusable pay calculation function.

**Concepts:** Functions, modules, imports, parameters, return values, and arithmetic logic.

### Video Rental Discount Calculator

An expanded version of the rental calculator that applies a 20% promotional discount when a customer meets the required rental or spending threshold.

**Concepts:** Conditional logic, Boolean values, calculations, and program flow.

### Grade Calculator

Converts a numerical score into a letter grade using conditional statements.

**Concepts:** `if`, `elif`, `else`, comparison operators, and decision-making logic.

### Number Guessing Game

An interactive guessing game where a random number is generated and the player and computer make guesses until the correct number is identified.

**Concepts:** Random number generation, loops, user input, comparisons, and program control.

### Customer Feedback Question Report

Processes customer feedback from a text file, identifies questions within the feedback, associates questions with customer names, counts the results, and creates a report.

**Concepts:** File handling, string processing, lists, loops, functions, and basic reporting.

### Conversational Therapy Chatbot

An interactive conversational program that generates responses using predefined phrases, qualifiers, word substitutions, and basic text-processing techniques.

**Concepts:** String manipulation, dictionaries, lists, functions, conditionals, and conversational program design.
